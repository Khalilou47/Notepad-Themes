# Notepad-Themes
Themes for Notepad ++
01-Close Notepad++
02-Download the file you want
03-Copy the file to "C:\Program Files\Notepad++\themes"
04-In case that didn't work copy the file to "%APPDATA%\Notepad++\themes"
05-Open Notepad++
06-Got to Settings -> Style Configurator
